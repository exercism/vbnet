# Learning Visual Basic

## Websites

Visual Basic has evolved significantly over the years, and many third-party tutorials refer to outdated tooling or features.
The [official Visual Basic documentation](https://learn.microsoft.com/en-us/dotnet/visual-basic/) is the most current and reliable place to start your journey.

## The .NET Ecosystem

Visual Basic runs on the .NET runtime, sharing a lot of core functionality with C# and F#.
Therefore, understanding how .NET works will make you a stronger VB developer. 

- [What is .NET?](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [The .NET Glossary](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [The Common Type System (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
