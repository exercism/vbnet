# About

Write code that reads like plain English.

Visual Basic runs on the same .NET runtime as C# and F#.
You get LINQ, generics, and async/await, but the syntax is built to be read, not decoded.

If you already know C# or F#, the .NET runtime and libraries will be familiar.
If you know VB6, VBA, or VBScript, that familiar syntax is now backed by the battle-hardened .NET runtime.

No braces to balance, no semicolons to chase.
